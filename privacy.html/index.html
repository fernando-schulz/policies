Privacy Policy

Last updated: May 2026

1. Introduction

This Privacy Policy describes how schulz-video-generator ("the Application", "we", "the operator") handles information when the Application interacts with third-party platforms such as TikTok, YouTube, and Instagram. This is a personal, single-operator automation tool used exclusively by its developer to create and publish short-form video content. It is not a public-facing service, and it does not have end users beyond its single operator.

2. Information We Collect

The Application collects and processes the following limited categories of information:

  • OAuth Access Tokens: Authorization tokens issued by third-party platforms (TikTok, YouTube, Instagram) when the operator authorizes the Application. These tokens are used solely to authenticate API requests on behalf of the operator's accounts.
  • Video Content Metadata: Titles, descriptions, and tags provided by the operator for content to be published. This information is created and controlled entirely by the operator.
  • Platform API Responses: Temporary response data returned by third-party platform APIs (e.g., upload status, post identifiers) used only to confirm successful operations.

The Application does not collect, process, or store any personal data belonging to third parties, platform users, or any individuals other than the operator.

3. How We Use Information

Information collected by the Application is used exclusively for the following purposes:

  • Authenticating API requests to third-party platforms on behalf of the operator
  • Publishing video content created by the operator to the operator's own social media accounts
  • Confirming the success or failure of content publishing operations

No information is used for advertising, analytics, profiling, or any purpose other than the core publishing function described above.

4. Data Storage and Security

All data handled by the Application — including OAuth access tokens and content metadata — is stored exclusively on the operator's personal, private device. No data is transmitted to or stored on external servers, cloud services, or databases operated by the Application's developer. The operator is solely responsible for the physical security of the device on which the Application runs.

5. Data Sharing

The Application does not share, sell, rent, or otherwise disclose any information to third parties, with the following exceptions that are inherent to the Application's function:

  • Third-party platforms: When publishing content, the Application transmits video files and metadata to platforms such as TikTok, YouTube, and Instagram via their official APIs. This transmission is initiated by and controlled by the operator. Each platform's own privacy policy governs how that platform handles received data.

6. Third-Party Services

The Application integrates with the following third-party platforms. By using the Application to publish content to these platforms, the operator agrees to be bound by their respective terms and privacy policies:

  • TikTok — https://www.tiktok.com/legal/privacy-policy
  • YouTube / Google — https://policies.google.com/privacy
  • Instagram / Meta — https://www.facebook.com/privacy/policy

7. Data Retention

OAuth tokens and any operational data are retained on the operator's local device for as long as the Application is in use. The operator may revoke tokens and delete all Application data at any time by removing the Application and its associated credential files from the device, or by revoking access through each platform's account settings.

8. Children's Privacy

The Application is a personal developer tool and is not directed at, marketed to, or intended for use by individuals under the age of 13. No data from minors is knowingly collected.
